Prisma Access 5G Subscriber Lifecycle Guide

Compare how every 5G subscriber provisioning and telemetry step maps across the Web Portal, the CLI & REST API, and official Palo Alto Networks Strata Cloud Manager (SCM).

Open Strata Portal
1

Discover Organization Hierarchy & Subscriber Groups

Inspect TSG scoping and Zero-Trust policy user groups (Permissive vs Restrictive)

Discovery
1. Web UI Portal

Go to the Groups & Policies tab to view available security groups and active SIM counts. Top banner displays current active TSG hierarchy.

2. Python CLI & API
python manage_5g.py tenants
python manage_5g.py groups

Endpoints: GET /mt/manage/5g/tsgs & GET /mt/manage/5g/subscriber-groups

3. Strata Cloud Manager (SCM)
Top Bar → Tenant Hierarchy
Configuration → Mobile Security → Subscriber Groups (or Objects → User Groups)

Inspect group members, DNS Security profiles, and URL Filtering attachments.

2

Provision SIM Card / User Equipment (UE)

Register SIM hardware identity (IMSI / IMEI) and bind to APN sasetest

Control Plane
1. Web UI Portal

Click "Add Test SIM" button in the top banner, generate or input IMSI/IMEI, select APN sasetest, and click "Create SIM".

2. Python CLI & API
python manage_5g.py add \
  --imsi 208950123456789 \
  --imei 860123123456789 \
  --apn sasetest

Endpoint: POST /mt/manage/5g/ues

3. Strata Cloud Manager (SCM)
Configuration → Mobile Security → 5G Subscribers (UE)

The SIM card appears instantly in the tenant subscriber inventory table with associated APN mapping.

3

Verify Provisioned Subscriber in SASE Control Plane

Confirm indexing across Prisma Access tenant database and policy assignments

Control Plane
1. Web UI Portal

In the SIM Inventory tab, search or filter by IMSI. The record displays its IMSI, IMEI, APN, and assigned security badge (Permissive vs Restrictive).

2. Python CLI & API
python manage_5g.py list
python manage_5g.py get <IDENTITY_ID>

Endpoint: GET /mt/manage/5g/ues/{id}

3. Strata Cloud Manager (SCM)
Configuration → Mobile Security → Tenant UEs

Filter by IMSI or IMEI to inspect the exact provisioned record and tenant scope.

4

5G Session Start & IP Telemetry Injection

Carrier 5G Core assigns IP (10.56.0.195 in europe-west9) and binds Zero-Trust user identity

Data Plane Telemetry
1. Web UI Portal

In the 5G Sessions tab, fill IMSI, IMEI, APN, allocated IPv4 (10.56.0.195), and click "Attach 5G Session". Real-time confirmation log prints in console.

2. Python CLI & API
python manage_5g.py session-register \
  --imsi 208950123456789 \
  --imei 860123123456789 \
  --apn sasetest \
  --ipv4 10.56.0.195

Endpoint: POST /mt/manage/5g/register/ue

3. Strata Cloud Manager (SCM)
Activity → Traffic Logs / User Activity

All network traffic originating from 10.56.0.195 is dynamically tagged with Source User: IMSI 208950... without any client/agent on the device.

5

Agentless Threat Inspection & Zero-Trust URL Filtering

Real-time user plane security policy enforcement (wicar.org test block)

Security Enforcement
1. Connected Device (Endpoint)

Device attached to 5G APN browses to test URL (e.g. wicar.org). The browser instantly receives the Palo Alto Networks Zero-Trust Block Page directly injected by the 5G Core.

2. Automated Test Suite
python test_lifecycle.py

Verifies end-to-end policy execution, session state, and tenant clean-up.

3. Strata Cloud Manager (SCM)
Activity → Threat Logs & URL Filtering Logs

Log details display: Source IP: 10.56.0.195 • Source User: IMSI 208950... • Action: block-url • Rule: Block-High-Risk-IoT.

6

5G Session Terminate / Deregister

Release IP-to-IMSI binding upon cell handover, airplane mode, or disconnection

Data Plane Release
1. Web UI Portal

In the 5G Sessions tab, submit session termination or trigger deregister in the Lifecycle Runner pipeline.

2. Python CLI & API
python manage_5g.py session-terminate \
  --imsi 208950123456789 \
  --imei 860123123456789 \
  --apn sasetest \
  --ipv4 10.56.0.195

Endpoint: POST /mt/manage/5g/deregister/ue

3. Strata Cloud Manager (SCM)
Activity → Session Monitor

Active IP session mapping is aged out gracefully; subsequent traffic is no longer associated with the IMSI lease.

7

SIM Deprovisioning & Decommissioning

Purge SIM identity from tenant inventory upon contract termination or return

Decommission
1. Web UI Portal

In the SIM Inventory tab, click the "Delete" button next to the test SIM card.

2. Python CLI & API
python manage_5g.py delete <IDENTITY_ID>

Endpoint: DELETE /mt/manage/5g/ues/{id}

3. Strata Cloud Manager (SCM)
Configuration → Mobile Security → 5G Subscribers (UE)

Record is permanently purged from tenant database, preventing any future traffic association.
